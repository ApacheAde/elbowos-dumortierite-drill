# Dumortierite Drill

Full-colour Python 3 neon shaft-drill arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a spinning gold bit down a denim-violet dumortierite shaft.
Thread sliding vein gaps, bag cyan cores, skip magenta fracture seams.
A / D or arrows steer. R resets.

## Play

```
pip install -r requirements.txt
python3 dumortierite_drill.py --play
```

## Record a 9:16 reel

```
python3 dumortierite_drill.py --record
```

Writes `DUMORTIERITE_DRILL_ElbowOS.mp4` (1080x1920, 15s, 30fps, h264).
